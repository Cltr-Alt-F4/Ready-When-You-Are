COLOR PALETTE REFERENCE
=======================

Primary Colors:
- Background: #1a1a2e (dark blue-gray)
- Grass: #2d4a3e (muted green)
- Dirt: #3d2e1f (dark brown)
- Stone: #4a4a5a (gray)
- Accent: #6b21a8 (purple for magic/undead)
- Highlight: #e94560 (red for danger)

Lighting:
- Torch light: #ffd700 (yellow-gold)
- Moonlight: #c0c0ff (pale blue)
- Lightning: #ffffff (white flash)
- Echolocation: #4ade80 (green spectral)

FILE FORMATS
============
- PNG format for all sprites (supports transparency)
- Spritesheets should have consistent frame sizes
- Keep file sizes optimized for web loading
- Consider using sprite atlases for performance

PRIORITY ORDER
==============
1. Phase 1 environment (graveyard tiles, hiding spots)
2. Character sprites (hider and seeker base)
3. Phase 2 environment (night cemetery, shrines)
4. UI styling (panels, buttons, HUD)
5. Effects (rain, lightning, lighting)
6. Power-up icons and effects

NOTES
=====
- All assets should be pixel art style
- Maintain consistent art direction throughout
- Test assets in-game before finalizing
- Ensure good contrast for gameplay visibility
- Support both mobile and desktop resolutions
